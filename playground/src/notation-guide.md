# aozora-md 記法リファレンス

aozora-md（Aozora Flavored Markdown）は **CommonMark + GFM** に **青空文庫記法**
を重ね合わせた記法です。ふつうの Markdown をそのまま書きつつ、ルビ・傍点・
縦中横などの日本語組版を `［＃…］` の注記で表現できます。

## 記法の仕様

それぞれの記法の詳細は本家の仕様書を参照してください。aozora-md は三つを
そのまま重ねたもので、独自の記法は追加していません。

- [青空文庫記法 仕様](https://p4suta.github.io/aozora-notation-spec/) —
  ルビ、傍点、縦中横、外字、字下げ、見出し注記、改ページなど
- [CommonMark 仕様](https://commonmark.org/) — 見出し、強調、リスト、引用、
  コードブロック
- [GitHub Flavored Markdown](https://github.github.com/gfm/) — 表、取り消し線、
  タスクリスト

## 混在のしかた

純粋な CommonMark / GFM 文書はそのまま同じ HTML になります。青空文庫記法の
拡張は、入力が実際に使った箇所でのみ発動します。

```
# 第一章

彼は｜青梅《おうめ》に行った。
可哀想［＃「可哀想」に傍点］な人。

| 左 | 中央 | 右 |
|:---|:---:|---:|
| ｜漢字《かんじ》 | ~~取り消し~~ | ［＃改ページ］ |
```

コードブロックとインラインコードの中では、青空文庫記法は解釈されず、書いた
とおりの文字がそのまま出力されます。

## 縦書きと横書き

ツールバーの「縦書き / 横書き」で、プレビューの組方向を切り替えられます。
ルビ・傍点・縦中横は組方向に追従します。

## エディタの便利機能

- **記法で囲む**: テキストを選択してツールバーの「囲む」から、ルビ・傍点
  などで囲めます（`Ctrl/Cmd+Alt+R` でルビ、`+B` で傍点）。
- **共有リンク**: 「共有リンクをコピー」で、今の内容を URL に埋め込んで
  共有できます。
- **配色**: ツールバーの配色ボタンで、自動 / ライト / ダークを切り替え
  られます。
